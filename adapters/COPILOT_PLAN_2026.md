# GitHub Copilot Plan mode — documentation-backed illustrative workflow (2026-10-19)

Official documentation: https://docs.github.com/en/copilot/how-tos/copilot-in-your-ide/use-copilot-agents/use-plan-mode

In a throwaway repository, request a read-only design comparison before changing
code. Supply the existing routing contract, case oracle, two prototypes, and
non-functional constraints. Ask for risks, measurable questions, and reversibility.
Capture the generated plan and compare it to the reference ADR. The Plan mode
is documented as drafting and reviewing a plan before code changes; it does
not grant business or architecture acceptance authority. This guide was not
executed with a live Copilot client for CP05.
