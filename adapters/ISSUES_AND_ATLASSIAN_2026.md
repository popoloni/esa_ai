# Optional evidence collection: Issues and Atlassian Rovo MCP

Checked official vendor overviews (19 October 2026):
- GitHub Issues quickstart: https://docs.github.com/en/issues/tracking-your-work-with-issues/learning-about-issues/quickstart
- Atlassian Rovo MCP overview: https://developer.atlassian.com/cloud/rovo-mcp/
- Rovo MCP setup: https://developer.atlassian.com/cloud/rovo-mcp/guides/getting-started/

GitHub Issues can be used to record requests, labels, owners and decisions; it is not a source of policy authority merely by existing. Rovo MCP can connect supported AI clients to Jira, Confluence and other Atlassian resources under their documented authorization flow. This chapter does **not** authenticate to a workspace, fetch any actual corporate materials, or test an external MCP host. Tokens, third-party credentials and sensitive records must not be copied into the public teaching case.

For the offline route, use the local `reader_side/discovery/sources/` fixtures. For a real organization, treat retrieval outputs as source material with provenance, permissions and a separate decision owner. A stale wiki cannot override a current policy just because an agent found it.
