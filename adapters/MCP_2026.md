# Read-only MCP educational fixture (source version 2025-11-25)

The file `reader_side/mcp/contract_server.py` demonstrates a small subset of the stdio transport with JSON-RPC. A trusted client launches the server and speaks newline-delimited UTF-8 JSON-RPC. The server declares one tool: `get_record(record='contract' | 'archived_note')`.

**Do not auto-install or auto-connect this server.** Inspect its code; its process inherits the host's operating-system rights unless isolated externally. Do not put credentials in commands or unreviewed configuration. For production, use the official SDK, hardened sandboxing, identity checks and user approval appropriate to each client. This sample has no HTTP transport and no network access. Its tests do not certify production interoperability.
