**How it works:**
- **Layout matching:** `diagnose` matches the full column signature of the reference, recorded or native layout. It refuses zero matches and competing current layouts, and ignores a historical table with a different signature.
- **Read-only:** it opens the file read-only and does not create a missing file. It hashes the file before and after, and raises `RuntimeError` if the hash changed.
- **Cost:** `cost_summary` uses Decimal. It raises `ValueError` for non-numeric, NaN, infinite, negative, bool or missing values, and for an invalid accepted count.
