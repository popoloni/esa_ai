**Changes in `operations.py`**
- **`diagnose`:**
  - It opens the file read-only, never creates it, and requires schema version 3.
  - It matches the full column signature of the three named layouts plus the mapped `reservations_v3` from `docs/G4-SCHEMA-MAP.json`. Zero or more than one match raises `ValueError`.
  - It compares file digests before and after, and raises `RuntimeError` if they differ.
- **`cost_summary`:** it sums every attempt with `Decimal`. Non-numeric, `None`, bool, NaN, infinite and negative values raise `ValueError`. Zero accepted outcomes returns null unit metrics and `NO_ACCEPTED_OUTCOME`.
