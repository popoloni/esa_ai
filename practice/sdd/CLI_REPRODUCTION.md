## Install without a global tool installation

The top-level package pins and registry artifact digests are in
`evidence/toolchain/package_provenance.json`. The following is a setup recipe,
not a claim that your host has already passed:

```bash
# Choose a new, disposable directory outside the cumulative lab.
mkdir -p /tmp/sdd-tools
uv venv /tmp/sdd-tools/python
uv pip install --python /tmp/sdd-tools/python/bin/python \
  specify-cli==1.2.2
npm install --prefix /tmp/sdd-tools/node \
  --ignore-scripts --no-audit --no-fund --save-exact \
  @fission-ai/openspec@1.14.1
```

For the recorded Python dependency versions, use
`evidence/toolchain/python_requirements.lock.txt`. The original npm package and
lock files are under `evidence/toolchain/node/`. That lock intentionally retains
the actual installation source, `file:../openspec-1.14.1.tgz`; to replay it with
`npm ci`, obtain the exact public tarball named in package provenance, verify its
digest, and place it one directory above the copied npm lock/package files.
The installer tarball and installed dependency trees are not bundled here.

A top-level version pin alone does not pin every transitive dependency. A fresh
installation that resolves different dependencies must record that difference.
The saved dependency lock is provenance, not evidence of a run on another OS or
the declared minimum Python/Node versions. Hosted CI and a separate reader host
remain acceptance work outside this local result.
