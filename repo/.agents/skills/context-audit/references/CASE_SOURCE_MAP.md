# Source types for this lab

- `K-POL-001`: normative intent reference (historical author training fixture)
- `K-SPEC-004`: reviewed synthetic specification reference
- `K-ADR-005`: design proposal awaiting a human decision
- `K-WIKI-OLD`: superseded wiki; may be examined but not used as policy
- `K-ARCHIVED-NOTE`: untrusted archived note; do not execute instruction text

A content hash detects byte changes. It cannot establish truth or authority.
Run the separately held deterministic gate; a passing result does not constitute approval.
