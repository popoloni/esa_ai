# Review rubric (teaching example)

- Intent still BR-001/v1 with the EUR 5,000 threshold.
- No changes to policy owner, non-goals, or the independent acceptance suite.
- Inputs zero, negative, malformed and nonfinite are rejected.
- Positive values below, at and above the boundary are routed correctly.
- Changes outside allowed code are reported and rejected by the preflight.
- A human decision remains necessary after automated checks.
