Owner: fictional workshop coordinator. Authored teaching decision, case date 2025-05-17. The retained AP-G1 implementation passed the G1 public contract and stores the columnar table reservations with these columns in this order: reservation_id, trusted_member_id, asset_id, starts_at, ends_at, idempotency_key. This representation is now an authorized third source for G2 migration. Map each column directly to the same-named public field, preserving the integer identifier, all five string values and the original table. Apply exactly the existing G2 validation, duplicate-identity, overlap and transaction obligations before commit. The schema destination version remains 2. Reinitialization must not duplicate or reinterpret records. Same identity and payload must replay the original identifier.

This authorization is specific to that complete column signature. It does not permit guessing other representations. Unknown columns/mappings, two competing legacy tables, invalid rows, duplicate identities and overlaps still require a rollback and a further owner mapping. Preserve the two earlier authorized sources.

A separate protected test creates a record through it, migrates through the current candidate, then reads and replays that record through the public API. A second case challenges invalid retained data and unchanged bytes on refused migration.
