B4 proposal cards

B4-P01

Configuration provides a stable reference for interpreting an incident. This diagnostic builds its observations around that intended ledger and retains the path, policy and anchor comparisons in the report. It avoids mixing evidence from uncertain locations while producing the existing status shape. The review should establish that the reported observations identify the state the running service actually selected.

Artifact: diagnose: the two state observations used by all subsequent comparisons.

selected, expected = (
    inspect_ledger(expected_path), inspect_ledger(expected_path))

B4-P02

Restoring the expected binding leaves requests in the extra ledger that the intended store has never seen. Reconciliation would copy those missing identifiers into the intended ledger after diagnosis and restoration. That would retain work performed during the incident and present operators with one history. The attached recovery plan preserves the existing diagnostic while this additional behavior is proposed.

Artifact: recovery_plan: the currently supplied plan; the proposed merge is a separate requested change.

return {
    "restore_configuration_to": diagnosis["expected"]["path"],
    "preserve_ledgers": [
        diagnosis["selected"]["path"],
        diagnosis["expected"]["path"]],
    "verification": [
        "historical replay",
        "current-policy decision on disposable copy",
        "restart and state binding"],
    "automatic_merge": False,
    "reconciliation": "PENDING_OWNER_DECISION",
    "production_authorized": False}

B4-P03

Both selected paths are inspected read-only, and each observation carries its own state identity. The resulting plan preserves the ledgers while identifying the expected binding and the checks needed after an authorized restoration. Records created during the incident remain a separate reconciliation decision. Matching decision identifiers alone do not settle whether the same historical state was selected.

Artifact: diagnose: state selection and returned status, around the path, policy and anchor comparisons.

selected, expected = (
    inspect_ledger(selected_path), inspect_ledger(expected_path))
