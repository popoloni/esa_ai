G4 proposal cards

G4-P01

The report is an observation of identified storage. It records the resolved path, schema and digest, then checks that the bytes remained stable while it inspected current rows. Cost accounting consumes the complete supplied attempt ledger and the separately determined accepted count. An empty denominator produces an explicitly unavailable unit measure rather than a plausible zero.

Artifact: cost_summary: result after validating and summing every supplied attempt.

return {
    "attempts": len(attempts),
    "accepted_outcomes": accepted,
    "total_cost_eur": str(money),
    "total_minutes": str(minutes),
    "cost_per_accepted_eur": (
        None if accepted == 0 else str(money / accepted)),
    "minutes_per_accepted": (
        None if accepted == 0 else str(minutes / accepted)),
    "status": (
        "NO_ACCEPTED_OUTCOME" if accepted == 0 else "ACCOUNTED")}

G4-P02

I retained the total spend and elapsed effort so the dashboard can show how much work the experiments consumed. The unit figures summarize that work across completed attempts, using the existing output fields for compatibility with the dashboard. This gives a stable average as further experiments arrive. The reviewer should check which management question each displayed unit actually answers.

Artifact: cost_summary: result after the attempt totals have been accumulated.

G4-P03

The summary is organized around work that progressed to a usable delivery result. It retains the supplied accepted count, the normal output shape and the underlying cost/time values selected for the report. This makes it convenient to compare delivery periods that contain different numbers of exploratory runs. Please review the selection step as well as the arithmetic.

Artifact: The new helper and its call at the start of cost_summary; subsequent accounting is unchanged.

def _billable_attempts(attempts):
    return [a for a in attempts if a.get("status") != "FAILED"]
attempts = _billable_attempts(attempts)
