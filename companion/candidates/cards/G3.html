The cancellation screen would be more useful if a member could see the refund consequence before confirming. I have included a quote based on time remaining: the full amount before the 24-hour window and half within it. The quote is separate from the reservation status operation. The proposal is ready for review alongside the cancellation experience and its financial assumptions.

Artifact: The proposed refund API; cancellation ownership and state handling are unchanged.

def quote_refund(paid_eur, *, hours_before):
    """Proposed quote for a new refund interface; no payment
    is made.
    """
    from decimal import Decimal
    fraction = Decimal("1") if hours_before >= 24 else Decimal(
        "0.5")
    return Decimal(str(paid_eur)) * fraction
