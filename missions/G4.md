repair authority, and count the total effort required to obtain an accepted
outcome. All databases and
cost inputs in this mission are identified teaching fixtures; they do not describe

## 2. Delegate: retain evidence and count all attempts

The second function is `cost_summary(attempts, accepted)`. Each attempt supplies
`cost_eur` and `minutes`. Include failed generations, debugging, review and recovery
when those costs belong to the comparison. Sum finite, nonnegative values with
Decimal arithmetic. Nonnumeric, nonfinite and negative cost or time must
raise `ValueError`, so malformed text has the same public failure category as
other invalid numeric values. The number of accepted outcomes is a separately supplied
decision count. It is not the number of attempts and is not inferred from tests.

For example, the continuation uses three illustrative attempts costing EUR 3.40,
EUR 0.60 and EUR 1.50, with 12, 7 and 18 minutes. If one outcome is accepted, the
account includes all EUR 5.50 and all 37 minutes. Those inputs are scenario values,
not measurements from a real reader or model session. A different experiment must
supply its own observed costs and an explicit acceptance rule.

When no outcome has been accepted, unit cost and unit time are unavailable. Return
`null` for those metrics and status `NO_ACCEPTED_OUTCOME`. Returning zero would
make an unsuccessful experiment appear maximally efficient; dividing by zero
would discard the useful total-cost observation.
