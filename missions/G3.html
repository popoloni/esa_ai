G3. Cancel without erasing the past

Run commands from the package root. Live-client setup and current status · Offline recorded tours

Session planning target: setup 10 min · implementation 30 min · review and handoff 20 min (60 min total). Plan a separate session for the two-contribution integration below.

A member cancels, a stale tab retries, and the original reservation request arrives again. Delegate the state change while preserving what each caller can observe. RES-002/v1, dated 19 May 2025, supplies the teaching owner’s approved behavior; neither an agent nor a checker grants new policy authority.

Identity and version are mandatory keyword-only inputs, with no defaults:

           expected_version):
    ...

The boundary supplies trusted identity and a valid integer version. This local module does not authenticate network users.

Table: Cancellation outcomes and retained state.

Condition Result State effect
Unknown reservation 404/not-found None
Caller is not the owner 403/not-owner None
Expected version is stale 409/stale-version None
Active reservation, owner and version match 200/cancelled Cancelled; version increments once
Already cancelled, current version supplied 200/already-cancelled No further increment

A repeat with the old version is stale even after cancellation. Predict an active version 1 reservation, successful cancellation to version 2, repeats with versions 1 and 2, and a request from another member. Include preserved state.

Artifact: The proposed refund API; cancellation ownership and state handling are unchanged.

def quote_refund(paid_eur, *, hours_before):
    """Proposed quote for a new refund interface; no payment
    is made.
    """
    from decimal import Decimal
    fraction = Decimal("1") if hours_before >= 24 else Decimal(
        "0.5")
    return Decimal(str(paid_eur)) * fraction
