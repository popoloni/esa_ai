Recorded agent tours

These guided tours use retained ChatGPT Work coding-worker recordings. They do not launch a client or establish human proficiency. Keep each decision before revealing the next outcome.

Run from the package root. Create a new trace directory for every attempt.

python3 companion/agent_session.py trace --task AP-G1 --output work/trace-g1

Write your observation, next action and reason in a text file, then continue:

python3 companion/agent_session.py trace --session work/trace-g1 --decision-file work/my-decision.txt

The command shows the next observation only after retaining your note. The raw evidence below can reveal later outcomes; use it after your staged decisions.
